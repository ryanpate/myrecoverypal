## How to use the Nano Banana prompts

Each prompt assumes you **attach the real product photo** (path given per post, from `media/products/`) so the generated ad keeps the actual design instead of inventing one. Paste the photo + prompt into Gemini (Nano Banana model). Ask for **1080×1080 (1:1)** for feed posts; regenerate at **1080×1350 (4:5)** if you want the taller feed format.

## Posting notes

- **Instagram:** links in captions aren't clickable — keep the shop link in your bio and use "link in bio" CTAs. First line is the hook (shown before "…more").
- **Facebook:** paste the product link directly in the post; FB auto-generates a link preview (you can delete the raw URL after the preview loads and keep the uploaded image instead).
- **Tone guardrails:** never imply the reader has a problem ("struggling? buy this") — speak about the message/product, not the reader's status. This also keeps copy safe for Meta's personal-attributes ad policy if you later boost a post.
- Space posts out ~2–3 per week; alternate apparel / journals / accessories.
